사람들이 AI Agent를 가장 많이 쓰는 분야

최신 survey와 제품 신호를 기준으로 개인 사용, 기업 배포, 개발자/IT 사용을 분리해 정리했다. 결론은 기업 기준 고객지원과 리서치/데이터 분석, 개인 기준 조사/요약과 생산성 보조가 가장 강하다는 것이다.

1. Executive Summary

한 줄 결론: 현재 AI Agent 사용이 가장 많이 확인되는 분야는 기업 기준으로는 고객지원/컨택센터와 리서치/데이터 분석이다. 개인/지식근로자 기준으로는 조사/요약, 정보 탐색, 글쓰기, 개인 생산성 보조가 가장 강하다.
1위 축고객지원, 컨택센터, CRM. LangChain 2025의 primary deployment 1위이며 Deloitte/PwC도 agentic AI의 최우선 영향 영역으로 본다.
2위 축리서치, 요약, 데이터 분석, 지식관리. agent가 여러 출처와 도구를 순차적으로 다루기 쉬운 영역이다.
성장 축IT, 개발, 사이버보안. 전략 중요도는 높지만 Stack Overflow 2025 기준 개발자 agent 사용은 아직 mainstream이라고 보기 어렵다.

2. What Changed

구분2024년 신호2025-2026년 신호해석
Agent 사용처 LangChain 2024는 research/summarization 58%, personal productivity/assistance 53.5%, customer service 45.8%를 상위 사용처로 제시. LangChain 2025는 실제 primary deployment 기준 customer service 26.5%, research & data analysis 24.4%, internal workflow automation 18%를 제시. 실험/기대 단계에서는 지식 작업과 생산성이 강했고, production 배포 단계에서는 고객지원과 데이터/리서치가 앞선다.
기업 확산 단계 여러 산업에서 agent production 계획이 높다는 신호. McKinsey 2025는 62%가 agent를 실험 중이거나 scaling 중이지만, 개별 기능별 scaling은 10%를 넘지 않는다고 설명. 관심은 넓지만 scale은 아직 초기다. 기능별로는 좁고 검증 가능한 업무부터 간다.
개발/IT coding assistant와 autocomplete 중심. Stack Overflow 2025 기준 개발자 agent daily 사용은 14.1%, weekly는 9%다. 개발/IT는 빠르게 agent화되지만 일반화까지는 품질, 신뢰, 권한 통제가 병목이다.

고객지원이 1위로 보이는 이유

  • Confirmed fact: LangChain 2025는 primary agent use case 중 customer service를 26.5%로 가장 흔한 배포처라고 제시했다.
  • Confirmed fact: Deloitte 2026은 agentic AI가 customer support에서 가장 큰 impact를 낼 것으로 봤다.
  • Confirmed fact: PwC 2025는 AI agent를 쓰거나 6개월 내 쓸 계획인 기업 중 customer service/support가 57%, sales/marketing 54%, IT/cybersecurity 53%라고 보고했다.
  • Interpretation: 고객지원은 자연어 요청이 들어오지만 뒤의 처리는 lookup, refund rule, ticket update, escalation, response draft처럼 tool call과 workflow로 쪼개진다.

5. AI Platform and Service Implications

우선 투자 순서
  1. 고객지원/CRM agent
  2. 리서치/데이터 분석 agent
  3. 내부 워크플로/employee service agent
  4. IT/개발/보안 agent
  5. 세일즈/마케팅/content agent
공통 플랫폼 기능
  • Agent identity, scope, owner
  • Tool permission matrix
  • Execution ledger and trace
  • Human escalation and approval
  • Evidence and citation layer
  • Domain eval suite
  • Artifact review surface

6. Recommended Actions

  1. 고객지원과 리서치/데이터 분석을 첫 번째 benchmark use case로 잡는다.
  2. 분야별 agent registry를 만든다: customer support, research, productivity, IT/security, sales/marketing, back-office.
  3. 고객지원 agent는 자동 답변보다 triage, draft, retrieval-grounded answer, escalation부터 시작한다.
  4. 리서치/데이터 agent는 citation, source ranking, stale-source warning, data lineage를 기본 기능으로 둔다.
  5. 개발/IT/보안 agent는 worktree/sandbox, read-only default, production write approval, incident replay를 최소 조건으로 둔다.
  6. 30일 안에 분야별 adoption metric을 정한다: deflection rate, answer acceptance, cycle time, human edit distance, escalation rate, tool error, policy violation, cost per completed task.
