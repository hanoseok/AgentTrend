1. Executive Summary

OpenAI Codex Work Claude Code Expertise Google ARD GitHub Agent Finder Microsoft Build 2026
핵심 판단 1: agent는 작업 단위가 됐다

OpenAI Codex 연구는 30분-8시간 이상 사람 업무로 추정되는 delegated task 사용이 빠르게 늘고 있음을 보여준다. agent는 chat answer가 아니라 work queue에 가까워진다.

핵심 판단 2: discovery와 registry가 표준화된다

Google ARD와 GitHub Agent Finder는 agent marketplace가 capability metadata, trust, permission, organization routing을 요구하는 방향으로 움직인다는 신호다.

핵심 판단 3: governance와 eval이 병목이다

Microsoft Agent 365, NIST identity/authorization, Patronus digital world models는 agent 확산의 다음 병목이 권한, 관찰, simulation, 검증임을 보여준다.

이번 회차 결론: AI 플랫폼이 지금 설계해야 할 핵심 layer는 agent job API, ARD/Agent Card registry, agent identity/authorization, artifact review surface, expertise scaffold, simulated eval/replay다.

4. Product / Platform Detail

OpenAI Codex: measurable agentic labor

OpenAI Codex research

OpenAI는 agentic AI가 minutes/hours 단위 delegated task로 이동한다고 설명했다. Codex가 Engineering뿐 아니라 Legal, Finance, Recruiting에서도 primary AI tool이 되었다는 점은 developer tool이 work operating layer로 확장되는 신호다.

Anthropic Claude Code: expertise remains a multiplier

Claude Code expertiseEconomic Index

Claude Code 분석은 사용자 전문성이 session success와 연결됨을 보여준다. agent 플랫폼은 novice 사용자가 일을 잘 맡기도록 task decomposition, acceptance criteria, reviewer checklist를 제품화해야 한다.

Google ARD + GitHub Agent Finder: discovery as infrastructure

Google ARDGitHub Agent Finder

Agent discovery는 검색 기능이 아니라 orchestration metadata 문제다. 어떤 agent가 어떤 task/capability를 갖고 어떤 trust/policy로 호출 가능한지 machine-readable해야 한다.

Microsoft Agent 365 + NIST: managed agents

Microsoft Build 2026NIST concept paper

기업 도입은 agent 생성보다 agent inventory, policy, identity, authorization, lifecycle 관리가 먼저 병목이 된다. 이는 Microsoft의 Agent 365 방향과 NIST의 identity/authorization 의제가 맞닿는 지점이다.

Patronus / Jules / LangGraph: eval and runtime maturity

Patronus Series BGoogle Jules evalLangGraph 1.0

agent 운영의 핵심은 실제 업무 환경에서 실패 없이 완료하는가다. framework와 eval vendor 모두 stateful execution, observable trajectory, simulated environment, domain eval로 이동한다.

6. Watch Signals

  1. ARD/Agent Finder가 GitHub 외 다른 IDE, agent marketplace, enterprise catalog에 채택되는지.
  2. OpenAI Codex와 Claude Code의 non-engineering use case가 legal/finance/recruiting/customer support에서 얼마나 안정적으로 반복되는지.
  3. Microsoft Agent 365류 관리 계층이 실제 inventory, policy, incident response, decommissioning까지 제공하는지.
  4. NIST identity/authorization 논의가 vendor implementation, OAuth/MCP/A2A/ARD metadata에 반영되는지.
  5. Patronus류 digital world model이 enterprise procurement/eval 기준이 되는지.
  6. agent 사용량 증가에 따라 cost explosion, stale intent, permission leakage, artifact verification failure 사례가 증가하는지.
후속 확인: 이번 회차에서는 큰 M&A 신호는 확인하지 못했다. Funding은 Patronus AI Series B를 대표 신호로 기록하고, agent identity/eval/security funding을 계속 추적한다.
